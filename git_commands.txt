GIT COMMANDS USED IN THE ASSIGNMENT
===================================

mkdir git-assignment
    Creates the project folder on the local machine.

cd git-assignment
    Moves into the project folder.

git init -b main
    Initializes a new Git repository with 'main' as the default branch.

git add index.html about.html
    Stages the two HTML files for the first commit.

git commit -m "Initial commit: add index.html and about.html"
    Records the initial state of the project as the first commit.

git add index.html
    Stages the modified index.html.

git commit -m "Update index.html with intro paragraph"
    Records the modification to index.html as the second commit.

git branch feature
    Creates a new branch named 'feature'.

git switch feature
    Switches the working directory to the 'feature' branch.

git add about.html
    Stages the change made to about.html on the feature branch.

git commit -m "Add team description to about.html on feature branch"
    Commits the change to the 'feature' branch.

git switch main
    Switches back to the 'main' branch.

git merge feature --no-ff -m "Merge feature branch into main"
    Merges 'feature' into 'main', creating an explicit merge commit so the branch activity is visible.

git log --oneline
    Displays the commit history in a compact one-line-per-commit format.

git log --graph --oneline --all
    Displays the commit history as a graph showing branches and merges.

git status
    Shows the state of the working tree and staging area (also shows .log/temp/ are ignored once .gitignore exists).

git add .gitignore
    Stages the .gitignore file (it ignores *.log files and the temp/ folder).

git commit -m "Add .gitignore for .log files and temp/ folder"
    Commits the .gitignore file.

git commit -m "Add extra comment to index.html (to be undone)"
    Makes an additional commit (after git add index.html) that will be undone.

git reset --hard HEAD~1
    Undoes the last commit and discards its changes, moving the branch back one commit.

git remote add origin https://github.com/<username>/<repo-name>.git
    Connects the local repository to the public GitHub repository.

git push -u origin --all
    Pushes all local branches (main and feature) to GitHub and sets upstream tracking.

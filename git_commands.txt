GIT COMMANDS USED
=================

$ mkdir git-assignment && cd git-assignment
    I made a working directory and stepped into it.

$ git init -b main
    Started tracking the directory; the default branch is named main.

$ git add index.html about.html
    Put my two pages into the staging area.

$ git commit -m "Initial commit: add index.html and about.html"
    First checkpoint of the project.

$ git add index.html  /  git commit -m "Update index.html with intro paragraph"
    Second checkpoint, after I added a paragraph to the home page.

$ git branch feature
    Opened a side branch to experiment without disturbing main.

$ git switch feature
    Moved onto that side branch.

$ git add about.html  /  git commit -m "Add team description to about.html on feature branch"
    Edited the about page here, so only this branch has the change.

$ git switch main
    Went back to the main line.

$ git merge feature --no-ff -m "Merge feature branch into main"
    Pulled the side work in; --no-ff makes Git write a real merge commit I can point to.

$ git log --oneline
    Quick compact listing of past commits.

$ git log --graph --oneline --all
    Same listing drawn as a tree so the fork and merge are visible.

$ git status
    Shows what is modified, staged, untracked, and confirms ignored files are hidden.

$ git add .gitignore  /  git commit -m "Add .gitignore for .log files and temp/ folder"
    Saved the rules that make Git skip *.log files and the temp/ directory.

$ git commit -m "Add extra comment to index.html (to be undone)"
    A deliberately unnecessary checkpoint I could then take back.

$ git reset --hard HEAD~1
    Rolled the branch back one step, deleting that checkpoint and its edit from my files.

$ git remote add origin <url>
    Told Git where the online copy lives (done for me by gh repo create).

$ git push -u origin --all
    Sent main and feature to GitHub and set them to follow their online versions.

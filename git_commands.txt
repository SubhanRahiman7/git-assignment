GIT COMMANDS USED
=================

mkdir git-assignment
    Makes the folder that holds the project.

cd git-assignment
    Enters that folder so later commands act on it.

git init -b main
    Turns the folder into a Git repository whose first branch is called main.

git add index.html about.html
    Places both HTML files in the staging area, ready to be recorded.

git commit -m "Initial commit: add index.html and about.html"
    Saves a snapshot of the staged files as the first entry in history.

git add index.html
    Stages the edited index.html.

git commit -m "Update index.html with intro paragraph"
    Saves the index.html edit as the second snapshot.

git branch feature
    Creates a separate line of development named feature.

git switch feature
    Moves the working folder onto the feature branch.

git add about.html
    Stages the edit made to about.html.

git commit -m "Add team description to about.html on feature branch"
    Saves that edit on feature only, leaving main untouched.

git switch main
    Returns to the main branch.

git merge feature --no-ff -m "Merge feature branch into main"
    Brings the feature work into main and forces a merge commit so the branching stays visible.

git log --oneline
    Prints history with one short line per commit.

git log --graph --oneline --all
    Prints history as a text diagram including every branch and merge.

git status
    Reports which files are changed, staged or ignored.

git add .gitignore
    Stages the ignore file, which lists *.log and temp/.

git commit -m "Add .gitignore for .log files and temp/ folder"
    Records the ignore rules in history.

git commit -m "Add extra comment to index.html (to be undone)"
    Creates a throwaway commit used to demonstrate undoing.

git reset --hard HEAD~1
    Moves the branch back by one commit and throws away that commit's changes.

git remote add origin <url>
    Registers the GitHub repository as the remote named origin.

git push -u origin --all
    Uploads every local branch to GitHub and links them to their remote copies.
